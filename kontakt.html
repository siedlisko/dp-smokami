CSS .hero { /* Zapewnia pełną wysokość ekranu */ min-height: 100dvh; /* Rozciąga sekcję na pełną szerokość */ width: 100%; /* Opcjonalnie: wyśrodkowanie zawartości w pionie i poziomie */ display: flex; flex-direction: column; justify-content: center; align-items: center; } Dlaczego warto użyć 100dvh zamiast 100vh? 100vh: Ustawia wysokość na 100% widocznego obszaru, ale na urządzeniach mobilnych (np. Safari na iOS, Chrome na Androidzie) nie uwzględnia dynamicznie ukrywającego się paska adresu przeglądarki. Może to powodować niechciane przewijanie strony. 100dvh (Dynamic Viewport Height): Najlepsze nowoczesne rozwiązanie. Dynamicznie dostosowuje wysokość sekcji do zmieniającej się przestrzeni po schowaniu lub wysunięciu paska przeglądarki mobilnej. Użycie min-height zamiast zwykłego height gwarantuje, że jeśli treść na telefonie będzie długa, sekcja po prostu się powiększy, zamiast uciąć tekst. display: flex; justify-content: center; align-items: center; – zastępuje sztywne padding: 100px ... 80px, automatycznie wyśrodkowując cały tekst i przyciski idealnie w połowie wysokości ekranu. obraz w tle jest rchoce za ciemny, co tu zmienic? .history-hero { position: relative; background: linear-gradient(rgba(0, 0, 0, 0.65), rgba(18, 18, 18, 0.95)), url('{{ site.baseurl }}/assets/img/historia-hero.jpg') center/cover no-repeat; Aby rozjaśnić obraz, musisz zmniejszyć krycie (przezroczystość) w wartościach rgba() w linear-gradient.
